# Cozy Haven Tab

Tab Chrome custom : May look too fancy but intended for personal usage. Sesuaikan tema dan layout. Use your AI agent to do vibe code. Will fix some unecessary features later. End the end, it's just shortcut page.

## Fitur

- Shortcut kustom dengan kategori, drag-and-drop reorder, dan favicon otomatis
- To-do harian dengan sistem prioritas & XP
- Statistik shortcut tersering dibuka + meteran kerapian tab
- Catatan cepat dengan auto-save lokal
- Cuaca real-time via Open-Meteo (tanpa API key)
- 4 tema visual (Cozy Haven, Hollow Knight, Minimalist Focus, Moss Grotto), masing-masing mode terang/gelap
- Transisi *circular reveal* saat ganti mode terang/gelap
- Backup & restore data lewat file `.json`
- Navigasi penuh keyboard

## Keyboard Shortcuts

| Tombol | Aksi |
|---|---|
| `/` | Fokus ke pencarian |
| `N` | Tambah shortcut baru |
| `E` | Mode urutan kustom |
| `T` | Ganti mode terang/gelap |
| `Esc` | Tutup dialog |

## Teknologi

Manifest V3 · Vanilla JavaScript (ES Modules) · `localStorage` · Open-Meteo API — tanpa framework, tanpa build step.

## Instalasi
1. Clone this repo or download the zip
2. Extract it if you install via zip
3. Buka `chrome://extensions`
4. Aktifkan **Developer Mode**
5. Klik **Load unpacked**, pilih folder hasil ekstrak
6. Buka tab baru - done
